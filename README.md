# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- 可命名、可冻结的规划版本：同时保存箱体、物品身份/属性、三套摆放结果、风险和规则版本
- 按物品 ID 比较两个版本的增减、重量、装入/未装、位置和同名冲突；同名物品不会合并
- 只读回看历史版本；恢复前预览将被替换的当前内容，并自动把当前状态备份为新版本
- 历史版本不随装箱规则变化自动改写，只有用户显式按新规则重算时才生成新版本
- localStorage 本地保存与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排、风险规则与版本差异
- `src/ports`：工作区仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 版本与历史结果

保存版本会冻结当时的箱体、物品 ID 与属性、三套摆放结果、每套结果的风险清单，以及生成结果所用的规则版本。版本比较始终以物品 ID 为身份：同名但不同 ID 的物品会分别显示为删除和新增，不会合并；同一 ID 的属性、重量和三套方案装入差异会逐项展示。

旧版本是不可变快照。以后调整装箱规则时，旧版本仍按原结果回看；用户在版本查看器中明确选择“按当前规则重算”后，才会基于该版本输入生成一个新的命名版本。恢复版本前会先展示当前将被替换的内容，确认后把恢复前的当前状态另存为新版本；如果保存失败，当前编辑内容和结果保持不变。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

## Docker

```bash
docker compose up --build
```

访问 [http://localhost:8104](http://localhost:8104)。生产镜像由 Node 20 构建并由 Nginx 1.27 托管，已配置单页应用回退。
